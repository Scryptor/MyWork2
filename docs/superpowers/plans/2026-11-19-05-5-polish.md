> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** закрыть накопленные после планов 5.1–5.4 недочёты (заметки «План 5.5» в `docs/superpowers/plans/README.md`) и
добавить два маленьких недостающих правила: «Обязательно при выдаче» и «Привести написание в заказах к справочнику».

**Architecture:** работа сгруппирована по областям; каждая задача — набор пунктов из заметок с проверяемым
результатом и тестом на каждый пункт. Новое поведение только там, где заметка указывает на ошибку для человека;
остальное — без смены поведения (надёжность, тесты, токены).

**Tech Stack:** Rust (Axum 0.8, SeaORM 2, SQLite + PostgreSQL), SvelteKit 3 SPA, Svelte 5 (руны), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-15-ui-design-system-design.md` (6.2–6.6, 6.7, 6.8, 10, 11) и основная спека
`docs/superpowers/specs/2026-11-11-mywork3-crossplatform-design.md`; источник пунктов — «Заметки → План 5.5» в README.

## Review Focus

1. Выход из системы с несохранённой правкой и вход другим пользователем: правка или сохраняется, или явно
   отвергается, но никогда не уходит от имени второго пользователя; данные первого не видны второму.
2. Массовое действие, в котором не прошёл ни один заказ: выбор остаётся, уведомление говорит, что ничего не сделано.
3. Удаление фото с «Отменить»: фото возвращается без следа на сервере; если окно закрыли или ушли со страницы —
   удаление всё равно происходит.
4. «Обязательно при выдаче» при массовой выдаче: заказы без обязательных полей не выдаются, остальные выдаются,
   уведомление называет число и причину.
5. Сервер останавливают во время переноса файлов черновика в заказ: перенос дожидается конца, файлы не теряются.

8. Право `order_dates_edit` проверяется до `begin_write()`; тест: отказ без права не берёт блокировку (как
   соседние проверки).
9. Кэш настроек обновляется, пока держится блокировка записи (`update_settings`, точки, справочники — общий
   помощник); тест: две параллельные записи — кэш равен последнему зафиксированному.
