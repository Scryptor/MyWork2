# План 5.9. Карточка заказа

Основание — [разбор карточки](../specs/2026-11-21-order-card-review.md). Рабочая ветка — `plan-5-9-order-card`.

| Задача | Где | Критерий приёмки |
|---|---|---|
| Порядок полей и фото | OrderFields, OrderPhotos | Клиент, работа и деньги идут подряд. У длинного альбома доступны предпросмотр, все фото и возврат к компактному виду |
| Записи мастеров | mw-db, mw-core, mw-api | Автор и местное время определяются сервером. Записи сохраняются отдельно от редактируемой заметки. Повтор запроса безопасен |
| Лента в интерфейсе | Панель и страница заказа | Видны записи конкретного заказа, более ранние подгружаются. Ошибка отправки позволяет повторить попытку |
| Многострочные справочники | mw-core | Подсчёт, переименование и объединение учитывают пункты по строкам и через запятую. Проверяется сохранность соседних пунктов |
| Проверка поставки | Rust, Svelte, Tauri | Прогнать проверки из AGENTS.md, контракт API, сквозные тесты в Chromium и WebKit, CI и сборку приложения |

## Решения при реализации

- Один общий порядок полей в панели и полной карточке. Мастер после контактов видит жалобу и результат работы, приёмщик — следующий за ними расчёт.
- У записи отдельный ключ отправки. Повтор после потери ответа возвращает уже созданную запись. Переход между заказами сохраняет черновик в памяти текущего сеанса. Для старых записей ленты применяется курсор по номеру, чтобы параллельное добавление не сдвигало страницы.
- Справочник различает точку в конце названия и пунктуацию введённой строки. Явно сохранённое название имеет приоритет. Существующие до обновления многострочные названия продолжают учитываться при подсчёте и замене.
