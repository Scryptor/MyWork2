## Заметки для следующих планов

- **План 3:**
  - общий построитель `search_text` для импорта и процедура переиндексации;
  - Unicode NFC перед индексацией;
  - после импорта с явными id вызвать `set_next_id` (PostgreSQL сам не сдвигает последовательность);
  - определить «пустую базу» с учётом стартовых данных;
  - группы доступа MyWork 2 не дают `users_manage` — импорт должен выдать его кому-то;
  - логины MyWork 2 сравнивались с учётом регистра — возможны столкновения `login_key`;
  - телефоны и гарантия — см. наблюдения по реальной базе (локальный файл `.superpowers/legacy-real-db-findings.md`, не в git).
- **План 5:**
  - сортировка по бренду/модели/мастеру сейчас по кодовым точкам с учётом регистра — нужны нормализованные колонки сортировки;
  - смена вида статуса, которым уже пользуются заказы, должна предупреждать.
  - CORS для источников Tauri (`tauri://localhost`, `http://tauri.localhost`); правило «изменяющие запросы только с JSON» остаётся;
  - решить, откуда интерфейс берёт `crates/mw-api/bindings/`;
  - логи в файл в папке данных;
  - десктоп запускает сервер через `mw_server::Server` на `127.0.0.1:0`;
  - даты в OpenAPI помечены `format: date-time`, но в API это местное время без смещения — клиент не должен добавлять `Z`/смещение;
  - `ApiConfig` строить только из фактического адреса прослушивания (закрыть поле `loopback`), чтобы десктоп не включил режим без входа на `0.0.0.0`.
- **План 9:**
  - за обратным прокси ограничитель попыток видит адрес прокси — нужен список доверенных прокси и `X-Forwarded-For`;
  - ограничитель считает IPv6 по одному адресу (/128) — для сервера в интернете считать по /64;
  - режим хоста (`0.0.0.0`) отключает режим без входа — интерфейс должен предложить создать администратора;
  - сервер на loopback за обратным прокси (nginx передаёт `Host` своего upstream) пропускает проверку `Host`, и режим без входа становится доступен снаружи — отказывать в режиме без входа при `Forwarded`/`X-Forwarded-For` или требовать пользователей;
  - попытка входа, отменённая по таймауту или обрывом соединения, остаётся засчитанной — нужен страж, прощающий попытку, если пароль не проверялся;
  - HTTPS и закрепление сертификата.
- **Общее:** добавить в CI `cargo-deny` (лицензии и уязвимости зависимостей) — сейчас лицензии проверяются вручную.
